    数据加载失败

    页面需要读取 data/team.json。如果你是直接双击打开的 HTML 文件， 浏览器会因同源策略拒绝读取本地 JSON。

    解决办法：在目录里起一个本地服务（任选一条）

    • python -m http.server 8080
    • npx serve .
    • Windows 下运行本目录的 serve.ps1

    然后访问 http://localhost:8080
